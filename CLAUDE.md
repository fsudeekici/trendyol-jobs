# trendyol-jobs

Get Trendyol jobs from the Lever API and save them in a clean model.

## Stack

- Python 3.12
- httpx
- pydantic
- pytest

## Rules

### Tests

- Test with real saved data, not fake data.
- Write tests first. Show they fail before writing the code.
- Never delete or weaken a test.

### Data

- Never lose data silently. Log it or raise an error.
- Never store personal data.

### Git

- One branch per task.
- Never use `git stash`.
- Never force push.

## Report after each task

1. **Result** — what was done.
2. **Checks** — what was run and what it showed.
3. **Decisions for me** — choices the user must make.
4. **Next step** — what comes next.
